## About

I build things that ship. Over the past year: an open-world game built in both Unity 6 and
Unreal Engine 5, a course-review platform used by 200+ students at my university, two browser
games on Three.js and canvas, a computer-vision pipeline that analyses table tennis matches
frame by frame, and a reinforcement-learning project that taught a quadruped robot to walk
in simulation.

Three years in the IDF on the Patriot missile system, finishing as a commander. Since then,
QA at Mindli and automation engineering at Agora, where I migrated a production test suite
from the UI layer to the API layer.

**Open to a part-time student software engineering role** alongside the degree, in real-time 3D,
full-stack product work, or applied ML.
